# PATOS — BASE DE CONOCIMIENTO

## Propósito
Este conjunto de archivos constituye la base de conocimiento estratégica y operativa de PATOS. Está preparado para ser utilizado como contexto por sistemas de IA, especialmente Claude, para desarrollar dossieres, presentaciones, propuestas, textos, diseños conceptuales, webs y otros materiales.

## Qué es PATOS
PATOS debe entenderse como una **matriz empresarial de proyectos, marcas y líneas de negocio** relacionadas con la música, la cultura, el entretenimiento y los eventos.

No debe entenderse únicamente como una agencia o proveedor de servicios. La estructura debe permitir crear y desarrollar proyectos con identidad, público, modelo de negocio y objetivos propios.

Web de referencia: https://www.patosagencia.com

## Principios de interpretación
- Diferenciar hechos de hipótesis y propuestas.
- No presentar ideas futuras como decisiones tomadas.
- No inventar clientes, artistas, acuerdos, cifras, capacidades o resultados.
- Priorizar criterio, rentabilidad, diferenciación y capacidad real de ejecución.
- Cuando falte información, indicarlo explícitamente.
- La arquitectura empresarial y la arquitectura de marca no son necesariamente iguales.
- No todos los proyectos tienen que utilizar públicamente la marca PATOS.

## Jerarquía documental
1. Identidad y posicionamiento.
2. Arquitectura empresarial.
3. Modelo de negocio y operaciones.
4. Proyectos y ecosistema.
5. Mercado, competencia y oportunidades.
6. Decisiones, hipótesis y banco de ideas.

## Estados de información
**VIGENTE / CONFIRMADO:** información que puede utilizarse como base actual.

**PROPUESTA / HIPÓTESIS:** planteamiento todavía no consolidado.

**PENDIENTE:** cuestión que requiere decisión o verificación.

**HISTÓRICO:** información válida para entender la evolución, pero no necesariamente vigente.

## Regla para generar materiales
Antes de crear cualquier material sobre PATOS, revisar la documentación pertinente y mantener separadas:
- identidad corporativa;
- servicios reales;
- proyectos activos;
- proyectos potenciales;
- decisiones tomadas;
- hipótesis;
- ideas.
