# Base de conocimiento

Esta bóveda guarda conocimiento reutilizable, decisiones y contexto de proyectos en archivos Markdown. Está pensada para poder usarse con Obsidian y compartirse con asistentes de IA sin depender de una base de datos propietaria.

## Dónde guardar cada cosa

- `00-Inbox`: capturas rápidas que aún hay que clasificar.
- `01-Memorias-IA`: contexto estable que puede reutilizar GPT, Claude u otros asistentes.
- `02-Proyectos`: una carpeta por proyecto activo.
- `03-Referencia`: documentación, guías y notas de consulta.
- `04-Plantillas`: formatos reutilizables para crear notas consistentes.
- `05-Archivo`: proyectos o notas cerrados.

## Rutina sencilla

1. Anota sin fricción en `00-Inbox`.
2. Clasifica cuando la nota tenga valor duradero.
3. Revisa `01-Memorias-IA` antes de iniciar trabajo importante con una IA.
4. Guarda los cambios en Git con mensajes claros y súbelos a tu repositorio privado.

## Convenciones

- Usa nombres cortos y descriptivos: `briefing-cliente.md`, `decisiones.md`.
- Enlaza ideas relacionadas con `[[Nombre de la nota]]`.
- No guardes contraseñas, claves API ni información financiera sensible en esta bóveda.
