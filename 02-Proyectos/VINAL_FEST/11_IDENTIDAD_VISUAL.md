# Identidad visual

## Dirección
Estética mediterránea, contemporánea y reconocible.

## Principios
- Impacto visual sin saturación.
- Sistema flexible para eventos y soportes cotidianos.
- Buena convivencia entre vino, música, gastronomía y territorio.
- Capacidad de adaptación a cada línea.

## Elementos a definir
- Logotipo
- Tipografías
- Paleta cromática
- Recursos gráficos
- Fotografía
- Ilustración
- Iconografía
- Motion
- Plantillas de redes
- Señalética
- Packaging
