# VINAL FEST

Base de conocimiento de VINAL FEST para Obsidian.

## Propósito
Centralizar la estrategia, identidad, formatos, operaciones, comunicación y evolución de VINAL FEST en una estructura modular de Markdown.

## ADN
VINAL FEST es una marca cultural, gastronómica y experiencial alrededor del vino. El vino es el hilo conductor de experiencias de disfrute, descubrimiento y encuentro.

## Principios
- Cercano, mediterráneo y contemporáneo.
- Vino sin elitismo ni tecnicismos innecesarios.
- Producto local y pequeños productores.
- Gastronomía, música y experiencias compartidas.
- El vino como experiencia, no como clase.
