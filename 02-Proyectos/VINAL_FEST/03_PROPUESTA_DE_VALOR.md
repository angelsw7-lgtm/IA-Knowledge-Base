# Propuesta de valor

## Para el público
Descubrir vinos y productos gastronómicos dentro de experiencias fáciles de disfrutar y compartir.

## Para bodegas y productores
Un contexto experiencial para presentar producto, generar prueba, visibilidad, comunidad y relación directa con público.

## Para artistas y cultura
Un entorno donde la música y la cultura forman parte de una experiencia con identidad.

## Para territorio e instituciones
Una herramienta para activar espacios, gastronomía, turismo, comercio y orgullo local.

## Beneficios
- Descubrimiento
- Socialización
- Experiencia
- Visibilidad
- Consumo
- Comunidad
- Activación territorial
