# MNN — Madrid Nuevo Norte

## Qué es este subproyecto

`MNN` es el primer territorio estratégico de MARDOS: un sistema vivo de inteligencia comercial y territorial construido alrededor del desarrollo urbanístico **Madrid Nuevo Norte**.

No es una carpeta de noticias sobre Madrid Nuevo Norte. Es la base desde la que MARDOS identifica actores, empresas, personas, proyectos y lugares vinculados a ese ecosistema, detecta necesidades y oportunidades de negocio, y convierte relaciones en reuniones y reuniones en negocio.

**Pregunta que gobierna el proyecto:** ¿qué está ocurriendo alrededor de Madrid Nuevo Norte y dónde puede existir una oportunidad para MARDOS?

## Relación con PATOS y con MARDOS

- **PATOS PRODUCCIONES** es la matriz: aporta experiencia, trayectoria, estructura, recursos y capacidad operativa.
- **MARDOS** es la marca que persigue oportunidades de negocio nuevas, con personalidad propia — puede presentarse como *MARDOS — powered by PATOS*.
- **MNN** es un subproyecto de MARDOS, no de PATOS. La documentación corporativa de PATOS no se duplica aquí: cuando haga falta explicar la capacidad de MARDOS ante un tercero, se remite a `02-Proyectos/MARDOS/` (identidad, manual de marca, base de conocimiento). MNN se concentra en qué oportunidad existe y cómo puede actuar MARDOS.

## Principios de trabajo (heredados del encargo)

- La bóveda es la fuente de verdad. Los dossieres, propuestas y presentaciones son productos derivados de lo que hay aquí, nunca al revés.
- Cada afirmación se etiqueta como **HECHO** (contrastado, con fuente y fecha), **INTERPRETACIÓN** (lectura nuestra sobre un hecho), **HIPÓTESIS** (posibilidad no confirmada), **OPORTUNIDAD** (posibilidad de negocio a investigar) o **ACCIÓN** (paso concreto que MARDOS puede ejecutar). Nunca se presenta una hipótesis como un hecho.
- No se inventan datos: empresas, personas, cifras, fechas o capacidades. Cuando falta información se deja indicada como pendiente, con la pregunta a investigar.
- Toda información que pueda cambiar con el tiempo lleva fecha de actualización y, cuando es posible, fuente.
- ChatGPT se usa para investigación, análisis y seguimiento de actualidad; lo que aporte de forma contrastada se incorpora aquí cuando sea relevante. Claude convierte el conocimiento ya estructurado en materiales (dossieres, propuestas, presentaciones) — Claude no es la fuente de verdad.
