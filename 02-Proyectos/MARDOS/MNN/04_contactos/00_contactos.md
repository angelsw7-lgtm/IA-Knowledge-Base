# 04 — Contactos

## Propósito de esta área

Registrar personas y relaciones dentro del ecosistema de Madrid Nuevo Norte: quién es, en qué empresa, qué cargo, cómo se ha identificado, qué relación tiene con MNN, cómo contactar, cuándo se contactó, en qué estado está la relación y cuál es el siguiente paso.

**No se inventan datos personales.** Esta nota no contiene ningún contacto todavía — se rellena únicamente con personas reales identificadas durante la investigación o el trabajo de campo.

## Registro de contactos

Una fila por persona. Cuando haya suficiente información sobre una persona, se puede convertir en nota propia (`04_contactos/nombre-apellido.md`) y enlazarla aquí.

| Nombre | Empresa | Cargo | Ámbito | Cómo se identificó | Relación con MNN | Contacto | Fecha de contacto | Estado | Próximo paso |
|---|---|---|---|---|---|---|---|---|---|
| *(sin registros)* | | | | | | | | | |

## Estados posibles

- **Identificado** — se sabe que existe, no se ha contactado.
- **Contacto iniciado** — primer mensaje, email o solicitud enviada.
- **En conversación** — hay intercambio activo.
- **Reunión conseguida** — hay o ha habido reunión.
- **En seguimiento** — a la espera de una respuesta o de un siguiente paso ya lanzado.
- **Sin recorrido** — se descarta por ahora (indicar motivo).
