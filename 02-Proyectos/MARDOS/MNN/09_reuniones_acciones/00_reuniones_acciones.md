# 09 — Reuniones y acciones

## Propósito de esta área

Registrar las acciones reales de MARDOS en MNN — no las planificadas (eso es [[06_agenda/00_agenda]]), sino las que efectivamente han ocurrido: reunión, contacto, llamada, email, LinkedIn, visita, evento, presentación, seguimiento. Cada interacción debe poder conducir a un siguiente paso explícito.

## Registro de acciones

| Fecha | Tipo de acción | Con quién ([[04_contactos]]) | Empresa ([[08_mapa_empresarial]]) | Resumen | Resultado | Siguiente paso |
|---|---|---|---|---|---|---|
| *(sin acciones registradas — el proyecto arranca el 27/09/2026)* | | | | | | |

## Regla

Toda fila nueva enlaza, cuando exista, a la nota de contacto y a la nota de empresa correspondientes (ver [[MARDOS_MNN_OPPORTUNITY_MAP]]). Una acción sin siguiente paso definido queda marcada como "cerrada sin seguimiento" explícitamente, no se deja en blanco.
