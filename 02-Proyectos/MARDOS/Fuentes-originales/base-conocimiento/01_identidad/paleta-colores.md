# MARDOS — Paleta de Colores

## Primario

| Nombre | Código | Uso |
|--------|--------|-----|
| Negro Primario | `#1a1a1a` | Wordmark, títulos principales, elementos sólidos |

## Secundario

| Nombre | Código | Energía | Uso |
|--------|--------|---------|-----|
| Naranja Energético | `#FF6B35` | ⚡⚡⚡ | Acentos, botones CTA, elementos destacados, propuestas |

## Neutrales (Escala de Grises)

| Nombre | Código | Uso |
|--------|--------|-----|
| Gris Muy Claro | `#f9fafb` | Fondos de secciones, tarjetas, áreas claras |
| Gris Bordes | `#e5e7eb` | Bordes sutiles, separadores, líneas |
| Gris Texto Secundario | `#9ca3af` | Subtítulos, descripciones, texto débil |
| Gris Texto Muy Débil | `#6b7280` | Metadatos, fechas, información menor |

## Monocromático (cuando no se puede usar color)

| Nombre | Código | Uso |
|--------|--------|-----|
| Negro Puro (100%) | `#1a1a1a` | Wordmark, títulos |
| Negro 75% | `#3f3f3f` | Texto de cuerpo, párrafos |
| Negro 50% | `#6b7280` | Texto secundario |
| Negro 25% | `#d1d5db` | Bordes, líneas sutiles |

## Contraste y Accesibilidad

Todos los contrastes cumplen **WCAG AAA** (máxima legibilidad):

- Negro `#1a1a1a` sobre Blanco: **21:1** ✓ AAA
- Naranja `#FF6B35` sobre Blanco: **5.2:1** ✓ AAA
- Naranja `#FF6B35` sobre Negro: **4.8:1** ✓ AAA
- Gris `#6b7280` sobre Blanco: **7.2:1** ✓ AAA

## Aplicaciones Estratégicas

### Propuestas Comerciales (PDF)
- Fondo: Negro `#1a1a1a`
- Wordmark: Blanco
- Acentos: Naranja `#FF6B35` en títulos y elementos destacados

### Email Signature
- Logo: Negro `#1a1a1a`
- Línea divisora: Naranja `#FF6B35`
- Texto: Gris `#6b7280` para metadatos

### Redes Sociales
- Fondo: Naranja `#FF6B35` (principal) o Negro `#1a1a1a` (alternativo)
- Texto: Blanco (máximo contraste)

### Web / Digital
- Fondo: Blanco o Gris Muy Claro `#f9fafb`
- Wordmark: Negro `#1a1a1a`
- CTA Buttons: Naranja `#FF6B35`
- Bordes: Gris Bordes `#e5e7eb`

### Print
- Primario: Negro `#1a1a1a` (puede ser 100% negro)
- Secundario: Naranja `#FF6B35` (Pantone o equivalente)
- Monocromático: escala de grises si es necesario

## Notas

- El naranja `#FF6B35` comunica **energía, creatividad y capacidad de ejecución**
- No es agresivo ni cálido excesivamente; funciona en contextos profesionales y creativos
- La paleta prioriza **legibilidad y accesibilidad** en todos los contextos
- El monocromático es obligatorio para: faxes, documentos legales, impresión de bajo costo
