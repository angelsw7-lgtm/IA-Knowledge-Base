# Prioridades y criterios de decisión

## Prioridades iniciales

1. Generar ingresos.
2. Repetir proyectos que ya se saben ejecutar.
3. Mejorar márgenes.
4. Construir cartera comercial.
5. Estandarizar procesos.
6. Consolidar una red fiable de proveedores y colaboradores.
7. Identificar y validar nuevas líneas de negocio.

## Marco de análisis

**Valor → Cliente → Problema → Solución → Diferenciación → Coste → Precio → Margen → Operativa → Riesgo → Repetibilidad → Escalabilidad**

## Distinciones obligatorias

- Facturación no es beneficio.
- Volumen no es rentabilidad.
- Un evento exitoso no implica un modelo de negocio exitoso.
- Un contacto no equivale a un cliente.
- Conocimiento operativo no siempre es ventaja competitiva.
- Una buena idea no es necesariamente una oportunidad comercial.
