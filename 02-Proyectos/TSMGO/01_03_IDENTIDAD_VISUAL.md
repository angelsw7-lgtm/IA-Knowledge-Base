# Identidad visual

## Objetivo
Crear un sistema visual propio para THE SHOW MUST GO ON.

Debe permitir convivir con:
- distintas bodegas anfitrionas
- El Corte Inglés
- marcas colaboradoras y partners
- artistas y contenidos musicales

## Pendiente
Logotipo, tipografías, paleta, sistema gráfico, fotografía, aplicaciones y piezas de campaña.
