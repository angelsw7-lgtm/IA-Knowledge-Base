# THE SHOW MUST GO ON

## Proyecto
THE SHOW MUST GO ON es un formato de experiencia que une enología, gastronomía y música en directo.

La primera edición se desarrolló en Bodegas Cerdá. El objetivo actual es convertir el concepto en un formato replicable y adaptable a otras bodegas.
