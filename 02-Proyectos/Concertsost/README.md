# Concertsost

## Rol en el ecosistema

Marca B2B independiente del sector de eventos, orientada a conexiones, alianzas, patrocinios, innovación y nuevos proyectos. Tiene identidad visual y una primera web aprobadas como base de trabajo.

## Fuente original

Todo el material recibido —Markdown, HTML e imágenes— se conserva sin alterar en `fuentes-originales/`.

## Regla de uso

Concertsost es independiente de Sabor a Música. No reutilizar su identidad, textos, activos ni posicionamiento en otras marcas salvo colaboración confirmada.

## Punto de partida

Leer `fuentes-originales/concertsost/00_MASTER.md` y después `04_DECISIONS.md` para conocer las decisiones vigentes.

## Estado actual (15/09/2026)

- Imagen destacada / Open Graph (redes sociales) generada con la línea visual de la marca y meta tags (og:*, twitter:*) añadidas al tema — verificado en vivo.
