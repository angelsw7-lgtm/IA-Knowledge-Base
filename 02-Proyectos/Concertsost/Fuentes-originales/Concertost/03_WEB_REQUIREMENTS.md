# CONCERTSOST — WEB REQUIREMENTS

## Objetivo
Crear una web que funcione como carta de presentación B2B y puerta de entrada para oportunidades, colaboraciones y proyectos.

## Usuarios
- Empresas
- Marcas
- Promotores y productoras
- Instituciones
- Partners
- Profesionales del sector
- Empresas relacionadas con turismo, tecnología, sostenibilidad y experiencias

## Sensación
La web debe sentirse actual, editorial, profesional y con personalidad.

## Principios
- Mensaje claro en pocos segundos.
- Mucha jerarquía visual.
- Diseño memorable.
- Animación solo cuando aporte.
- Excelente experiencia móvil.
- Preparada para crecer.
